## Use the PowerPoint flashcards

1. Download the PowerPoint and open it in **Slide Show** mode.
2. Choose a card. Say the full answer before selecting **Reveal Answer**.
3. Use **Try Again**, **Next Card**, or **Card Menu**. Each card identifies its PDF lesson page.
4. Review missed cards later. Explain each answer in your own words.

## What you will learn

- **Server roles:** DNS, DHCP, file, print, web, database, mail, AAA, syslog, and NTP.
- **Network appliances:** spam gateways, UTM, load balancing, proxies, SCADA, and IoT.
- **Cloud models:** IaaS, PaaS, SaaS; public, private, community, and hybrid deployment.
- **Cloud behavior:** shared and dedicated resources, multitenancy, elasticity, metered use, ingress/egress, availability, sync, and shared responsibility.
- **Virtualization:** hosts, guests, Type 1 and Type 2 hypervisors, requirements, virtual disks, snapshots, backups, NAT, bridged, host-only, sandboxes, legacy apps, containers, and VDI.
- **Practice:** 24 flashcards and a three-question quiz with encouraging explained answers.

Extra lab and hardware context is labeled where appropriate. Vendor examples are not universal product rules. Use current official objectives for complete exam scope.
