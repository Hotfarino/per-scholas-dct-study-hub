# RAID: Follow the Data

[Open the interactive guide](https://core-1-reviewed-flashcards.bigdawgroof812178.chatgpt.site/raid-workflow.html)

A colorful, plain-language companion to the network workflow guide. It covers RAID 0, 1, 5, 6 and 10, with definitions, acronym meanings, drive diagrams and explained examples.

- Choose a RAID level and follow a six-step read or write.
- Fail individual drives and rebuild recoverable arrays one row at a time.
- Compare RAID 10 failures within and across mirror pairs.
- Calculate usable capacity with mixed-size members and an optional spare.
- Click bits to see XOR parity and missing-block reconstruction.
- Explore Windows storage tools, controller views, repair procedures and performance terms.
- Review 20 click-to-flip cards, five configuration scenarios and a three-question quiz.
- Use optional device read-aloud for the current workflow step.

The simulator does not access real disks or measure the learner's computer. It models classic arrays with healthy surviving blocks and a functioning controller. Real rebuild timing, errors, cache behavior and layouts depend on the product.

CompTIA A+ Core 1 **220-1201**, objectives **3.4** (storage devices and RAID levels) and **5.2** (drive/RAID troubleshooting). Windows views provide practical context. These are original, independent exercises, not official or endorsed CompTIA questions.
