## Use the interactive flashcards

1. Download the PowerPoint and open it in PowerPoint **Slide Show** mode.
2. Pick a card from the menu. Say the full answer aloud before clicking **Reveal Answer**.
3. Use **Try Again**, **Next Card**, or **Card Menu**. Each card names the matching PDF lesson page.
4. Repeat missed cards later that day, then on later days. Explain the answer in your own words too.

The buttons use native slide links. No macros are required. This deck does not save scores or automatically schedule reviews. GitHub previews and PDF exports do not provide the same flashcard experience; download the PPTX for interaction. The PDF includes all 24 questions and answers for print practice.

## What you will learn

- **Standards:** 802.11a/b/g/n/ac/ax, Wi-Fi 4/5/6/6E, and clearly labeled Wi-Fi 7 extra context.
- **Radio terms:** RF, IEEE, GHz, MHz, PHY, throughput, bands, channels, channel width, DFS, and regional rules.
- **Performance:** MIMO, MU-MIMO, OFDMA, shared airtime, interference, antennas, coverage, and site surveys.
- **Connections:** SSID, BSSID, roaming, mesh, backhaul, hotspots, Wi-Fi Direct, and setup checks.
- **Security and nearby links:** WPA2/WPA3, SAE, Bluetooth pairing, NFC, and RFID.
- **Practice:** 24 flashcards plus a three-question quiz with explained answers.

Maximum PHY rates are theoretical standard ceilings, not promised download speeds. Wi-Fi range depends on equipment and surroundings; the guide does not assign a guaranteed distance to each standard. Local radio rules and device support matter.
