## What you will learn

- **Foundations:** software ports, clients/servers, IP addresses, protocols, TCP, UDP, and temporary client ports.
- **Files and remote access:** FTP 20/21, SSH 22, Telnet 23, SMB/CIFS 445, and RDP 3389.
- **Network setup and web access:** DNS 53, IPv4 DHCP 67/68 and DORA, HTTP 80, and HTTPS 443.
- **Mail and directories:** SMTP 25, POP3 110, IMAP 143, NetBIOS/NetBT 137–139, and LDAP 389.
- **Important distinctions:** FTP active/passive data, DNS over both transports, shared mailbox state, secure mail variants, SFTP versus FTPS, and HTTP/3 over UDP.
- **Practice:** two port maps, a website-loading mission, and three original questions with explained answers.

The main port maps cover objective 2.1. Extra secure-service ports and protocol-version details are clearly labeled as supporting context. The guide explains why software ports have no fixed physical distance or data rate.
