# Course Information

## Per Scholas Data Center Technician (DCT)

This hub supports the Per Scholas DCT course community with supplemental study material for:

- CompTIA A+ Core 1 (`220-1201`) concepts and performance-based questions
- Data-center support fundamentals: hardware, networking, cabling, storage, virtualization, cloud, printers, safety, and troubleshooting
- Professional development, labs, and peer study sessions

## How to use this hub

1. Start with the [category index](../CATEGORY-INDEX.md).
2. Use the [complete Core 1 study guide](../guide/core-1-study-guide.md) for concept review.
3. Practice with the [quizzes and labs](practice.md), then use the [video catalog](videos.md) for demonstrations.
4. Treat Canvas as the source of truth for assignments, deadlines, grades, and course announcements.

## Course-community references

Recent Discord updates include Lesson 12 cheat sheets, September 25 notes, RAID PBQ discussion, and Exam 1 retake guidance. These are indexed in the practice and attachment pages, but private Canvas/Discord files are not copied into this public repository.

This is an unofficial study companion. It does not replace instructor guidance, Canvas content, or the current official CompTIA objectives.
