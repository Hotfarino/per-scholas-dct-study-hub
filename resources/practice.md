# Practice Quizzes and Labs

## Peer-created browser quizzes

The course community shared three self-contained HTML practice files:

1. **Modules 1–4 Practice Exam** — 60 questions with classic, timed, and shuffled modes, explanations, and review.
2. **Modules 1–4 PBQ Lab** — five interactive tasks with 39 scored items.
3. **Earlier Modules 1–4 Quiz** — an additional review version.

The files are indexed but not redistributed publicly because permission from their authors has not been confirmed. Learners with authorized course access can locate them in the CompTIA help channel.

## Practice workflow

1. Take an untimed baseline quiz.
2. Record each miss by exam domain, wrong assumption, correct rule, and source.
3. Review only the weak sections.
4. Complete the PBQ tasks without notes.
5. Take the timed/shuffled variant.
6. Revisit questions you guessed correctly; a lucky answer is still a knowledge gap.

Peer-created answer keys can contain mistakes. Resolve disputed answers against the current official CompTIA exam objectives or authoritative vendor documentation.
